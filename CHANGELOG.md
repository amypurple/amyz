# Changelog

## Unreleased

- Added validated MSX1, SG-1000 and NES Warrior demonstrations with reproducible
  builds, emulator screenshots and byte-exact decoder harness results.
- Kept the palette-optimized NES conversion as the sole NES example. It aligns
  the image to the attribute grid and uses a bounded sprite overlay to preserve
  the face and red hair.

## 1.0.0 - 2026-11-23

- Stabilized the AMYZ token grammar and 15-bucket table format.
- Added optimal JavaScript, Python and C encoders.
- Added small, fast and tiny Z80 decoders for RAM and TMS9918A VRAM.
- Added ROM-safe and self-modifying 6502 decoders.
- Added TMS9900 RAM and VRAM decoders.
- Added reverse-stream and speed-aware encoding extensions.
- Added a C64 self-extracting packer.
- Published byte-exact corpus evidence and Graphics II benchmark results.
